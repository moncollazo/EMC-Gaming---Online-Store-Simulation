Color Palette: 
I chose a pink-dominated palette (#ffd1e8 for backgrounds, #ff69b4 for accents, #d63384 for hovers/emphasis) to evoke nostalgia from Barbie sites that I loved using
growing up. I wanted to create a cozy, feminine feel. Gaming sites often use dark, masculine colors targeting men (assumingly so since its their main audience), But I 
decided to flip that to appeal to women with softer shades that maintain vibrancy without overwhelming. This makes the site feel fun and approachable while ensuring 
readability (e.g., white text on gradients, dark pinks for prices). I find it really fun and sticks out compared to others. 


Overall Style/Theme: 
The website's style is inspired by nostalgic, playful aesthetics like old Barbie websites, combined with modern e-commerce layouts from gaming stores. I aimed for a fun,
feminine vibe using the rounded elements, grids for game displays (based off Epic Games), and smooth transitions to make navigation easy. The theme appeals to women 
gamers by using soft pinks and interactive features that feel are more welcoming rather than aggressive. For layout ideas, I drew from Epic Games for the bubble-like 
game cards in a home page grid, and Steam for detailed game pages with side-by-side images and specs and their about quote card sections but without the graphics. I 
consulted my brother and boyfriend, who both preferred Steam's structure, so I attempted to incorporated similar styling while adapting it to my pink theme.
